# Чат и настройка установленного приложения

## Что нужно сделать после установки на другом ПК

Файл настроек находится рядом с установленной программой:

`C:\Program Files\EDKAR\Clinic Statistics\appsettings.Local.json`

Не добавляйте этот файл в Git и не отправляйте его в общие чаты: он содержит секретные ключи.

### 1. Настроить MANGO OFFICE

В блоке `MangoApi` укажите действующие значения `ApiKey` и `ApiSalt`. Ключи передаются только по защищённому внутреннему каналу.

```json
"MangoApi": {
  "BaseUrl": "https://app.mango-office.ru",
  "ApiKey": "ПОЛУЧЕННЫЙ_КЛЮЧ",
  "ApiSalt": "ПОЛУЧЕННЫЙ_КЛЮЧ_ПОДПИСИ"
}
```

### 2. Настроить сервер чата

На текущем серверном компьютере имя сервера — `SERG`, адрес чата:

```json
"ChatServer": {
  "BaseUrl": "http://SERG:5088"
}
```

Если сервер перенесут на другой ПК, замените `SERG` на новое сетевое имя или статический IP-адрес. После изменения файла перезапустите приложение.

## Отложенные доработки чата

Вернуться к этому списку, когда будет отдельный запрос «вернёмся к доработке чата».

1. Добавить разделители дат в ленте сообщений.
2. Сделать ответ на конкретное сообщение с отображением цитаты.
3. Показывать уменьшенные изображения прямо в ленте чата, а не только в отдельном окне просмотра.
4. Настроить резервное копирование папки `ChatAttachments` на сервере `SERG`.
5. При необходимости расширить права администратора групп: журнал изменений состава, удаление групп и назначение дополнительных администраторов.
